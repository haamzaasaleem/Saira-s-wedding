# Saira & Asad — Wedding Invitation

A 3D animated, mobile-responsive wedding invitation website built with plain HTML, CSS and a little JavaScript.

Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).

## Editing details

- **Venues** — search `index.html` for `EDIT:` comments (event cards and the "Find Your Way" section / map link).
- **RSVP WhatsApp number** — set `RSVP_WHATSAPP` at the top of `script.js` (e.g. `"923001234567"`).
